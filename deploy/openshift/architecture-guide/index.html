01 / System map

How the demo fits together

The browser talks to a React UI, which uses a FastAPI service for application workflows and live agent conversations. The API coordinates role-aware LangGraph agents with model, identity, storage, and observability services.

Conversation path: Browser → UI → API → role-scoped agent → tools and services.Scroll horizontally on smaller screens.
01 / ACCESS

Three RBAC layers

Route checks, data scope filters, and per-tool authorization reinforce role boundaries.

02 / FAIR LENDING

HMDA data isolation

Demographic records use a separate schema and compliance access path; lending agents cannot query them.

03 / PRIVACY

PII masking

CEO views mask sensitive identifiers while retaining operational summaries.

04 / AUDIT

Hash-chained events

Agent actions and human decisions are recorded in an append-only audit trail.
